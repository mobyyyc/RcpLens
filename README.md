# RcpLens

An iOS-only personal purchase memory app. Import a receipt, correct it quickly, save it, split items with other people and find purchases later.

Status: approved planning; application implementation has not started. Xcode 27 and the iOS 27.0 simulator runtime are installed. Simulator AI readiness remains to be verified by T01.

Start with [MVP_PLAN.md](MVP_PLAN.md), [TASKS.md](TASKS.md), [PROGRESS.md](PROGRESS.md), and [docs/PRODUCT.md](docs/PRODUCT.md).

Build instructions will be added by T01 after verification. Private receipt images and extracted personal data must not enter Git.
