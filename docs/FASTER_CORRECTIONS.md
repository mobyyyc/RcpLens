## Review behavior

A compact **Check first** queue surfaces missing/invalid fields, source-linked interpretation warnings and arithmetic differences. It shows three pending checks initially, with Show all and an expandable checked group. Unpriced/wrapped text is one action group rather than a separate alert for every header. Raw diagnostic codes and confidence scores are not presented as accuracy claims. The full receipt form, paper preview, top Original action and Save draft remain available.

Opening a check gives a working copy of the relevant fields beside the original-photo region. Source-only groups have Previous/Next row controls, an explicit all-rows confirmation before marking a multi-row group checked, and optional explicit Add purchase / Link this row actions. Adding does not guess a description, amount, quantity or unit. Linking changes correction provenance only; original OCR IDs/boxes/observations, parser bytes and encoded photo stay immutable. Existing linked-line warnings show their complete linked image context; the displayed OCR snippet is only an aid and may contain errors.

Partial multi-row edits can be applied while the group remains pending. Apply commits explicit local edits; Cancel (including sheet dismissal) leaves the receipt and its confirmations unchanged. Description, quantity and amount use distinct keyboard-focus targets. Changed typed values must be valid or deliberately blank; an unrelated pre-existing malformed field does not block repairing another field. Save draft still rejects malformed typed input. The standard comparison uses a 150-point photo, one native control row, the amount field first and optional OCR text after edits. Image commands are scoped to each viewer; expanded zoom/reset preserves focused context. Long-image accessibility frames are restricted to the visible viewport. Original comparison offers zoom controls, expansion and Reset zoom, which returns to width-fit at the top of a scrollable full original. Missing coordinates fall back to the full original with a truthful explanation.

Checked guidance is stored with the encrypted review input and tied to deterministic signatures of relevant current values. It survives draft reopening and saved-receipt editing, and reopens after related changes/removal. Legacy installed review input decodes without the optional new checks. Subtotal/total checks cover both editable summary fields. Previously unassigned source groups retain their identity after manual linking/addition.

A focused check never sets full `sourceChecked`. Finish still requires explicit full source review, complete valid fields and exact deterministic reconciliation. Matching totals never establishes factual accuracy; diagnostics may miss omissions. Drafts retain Needs review and cannot finalize splits. Existing unfinished split choices remain available. No re-recognition feature was added: rerunning the unchanged OCR cannot resolve the established interpretation failures and would add an unnecessary replacement/duplication boundary. Existing failed-reading Retry/manual fallback remain unchanged.
