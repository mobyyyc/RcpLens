# Guided receipt camera verification

All preview images and injected capture data are fictional. The camera UI fixture requires Debug plus the explicitly isolated synthetic store. Normal Photos, Files and receipt contents were not captured or decrypted.

The feature adds Take a photo to Import, rear-camera capture with rounded corner guides, frosted guidance over the preview, glass controls, and an explicit Retake/Use photo check. Landscape places a usable guide beside the controls. Confirmation buttons follow the app's 44-point baseline; the shutter is 72 points. Large text wraps fully; the close icon stays inside its 44-point glass surface. The guide does not crop encoded originals. Capture uses local Vision/parser review after dismissal, with session/identity guards and the existing draft/finalization requirements.

Six unique native UI cases passed on iPhone 18 Pro / iOS 27.0, including existing empty-wallet light/dark import behavior. They cover retake, explicit use, real OCR, source access, saved-draft restart; cancellation and background discard; denied/restricted/unavailable alternatives and actual Simulator hardware discovery; failure/retry with large text, reduced motion, opaque controls and contrast; landscape and 44-point confirmation actions. `initial-six-test-summary.json` records that run. After final camera-only layout refinements, the three affected capture/large-text/landscape cases were rerun with final sources, all passing; see `final-three-test-summary.json`. The current images use final sources except denied/restricted/unavailable screens, whose layout is unchanged from the six-case run.

Initial visual review caught truncated guidance at the largest text size and rotation screenshots clipped by application screenshot bounds. Guidance now wraps over a contrast-preserving backing; evidence uses the complete screen after rotation settles. Landscape capture uses a side-by-side layout so the guide retains enough height.

Optimized Simulator and unsigned physical iPhone SDK builds pass. Generated metadata contains the camera purpose string and stable bundle identity; Simulator signature verifies. Both Release binaries exclude the Debug camera fixture and synthetic-store launch switches. The user's local Personal Team stays uncommitted. `source-sha256.json` identifies final application/test sources and the project with that local Team setting excluded.

The twelve normal encrypted receipts and original assets still match the earlier historical baseline. Wallet-settings ciphertext differed from that historical snapshot when checked during this task; the current settings snapshot was retained and remained unchanged through final tests and Release restoration. No settings were changed by this implementation. The checks read counts and ciphertext hashes only. Existing Xcode debugger lookup/diagnostic collection messages and the existing SwiftUI invalid-frame diagnostic appear in local results; test failures are zero.
